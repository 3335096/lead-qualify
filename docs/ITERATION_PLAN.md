# План итераций (MVP)

И1 — Bootstrap (каркас, БД, RBAC, webhook)
Критерии: миграции применяются, webhook 200 OK, basic auth работает.

И2 — LLM-оркестратор и квалификация
Критерии: `/v1/llm/extract` возвращает JSON; автоквалификация при $coverage \ge 0.8$ и $score \ge 40$.

И3 — Схемы и словари (Google Sheets)
Критерии: CRUD схем; редактор JSON с валидацией; sync словаря из Sheets; `optionsSource` влияет на подсказки.

И4 — CRM Inbox и статусы/причины
Критерии: список + карточка; смена статусов с reason_code (обязателен для негативных); ответ в TG.

И5 — SLA-демон
Критерии: напоминания до $T_{first}$; автозакрытие по $T_{inactivity}$ с reason `abandoned_timeout`.

И6 — Outbound + Дашборд
Критерии: отправка 2xx проходит; ретраи 5xx; `/dashboard` показывает summary за период.

И7 — Полировка и безопасность
Критерии: маскирование PII, аудит, OpenAPI, seed ниш, доки актуальны.
