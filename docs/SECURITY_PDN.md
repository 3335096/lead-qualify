# ПДн и безопасность (РБ, MVP)

- Хранение ПДн на Railway допустимо для MVP при шифровании AES-GCM (ключ `ENCRYPTION_KEY_HEX`).
- Минимизация ПДн: телефон, имя (опционально), telegram user id/username.
- Шифруются: phone, email. Маскирование в логах.
- Ретеншн сообщений: по умолчанию 6 месяцев (настраивается).
- Удаление/анонимизация по запросу субъекта.
- План миграции в национальный ЦОД — после MVP.
